## 1. 概述

### 1.1 产品定义
一款面试练习工具，用于技术面试准备。通过语音识别实时捕捉面试官问题，调用 AI 生成答案，以透明悬浮窗形式显示。

### 1.2 目标用户
- 准备技术面试的开发者
- 需要练习算法、系统设计、编程的求职者

### 1.3 核心价值
- 实时识别面试官问题
- 智能过滤无关内容
- 快速生成高质量答案
- 屏幕共享时不可见

---

## 2. 功能需求

### 2.1 语音识别模块
**功能：** 实时识别面试官语音

**技术要求：**
- 音频源：系统音频输出（腾讯会议）
- 识别引擎：Whisper（本地或 API）
- 实时性：< 2 秒延迟
- 准确率：> 95%（中文）

**智能过滤：**
- 区分面试官和用户声音
- 识别问题 vs 闲聊/指示
- 过滤短句、寒暄、指令性语言
- 仅在检测到真正问题时触发答案生成

### 2.2 答案生成模块
**功能：** 根据问题生成答案

**技术要求：**
- AI 服务：专属 API（兼容 OpenAI/Anthropic）
- 响应时间：< 3 秒
- 答案格式：
  - 问题复述
  - 完整答案
  - 关键点高亮
  - 代码示例（如适用）

**上下文管理：**
- 支持多轮对话
- 记忆面试上下文
- 理解问题关联性

### 2.3 界面显示模块
**功能：** 透明悬浮窗显示答案

**技术要求：**
- 框架：PyQt5/6
- 窗口类型：透明、无边框、置顶
- 屏幕共享时不可见
- 快捷键控制：`Ctrl + B` 显示/隐藏

**显示内容：**
```
┌─────────────────────────────────────┐
│  [问题] 面试官的问题                │
├─────────────────────────────────────┤
│  [答案]                             │
│  完整的答案内容...                  │
│                                     │
│  [关键点]                           │
│  • 要点 1                           │
│  • 要点 2                           │
│                                     │
│  [代码示例]                         │
│  ```python                          │
│  def example():                     │
│      pass                           │
│  ```                                │
└─────────────────────────────────────┘
```

### 2.4 音频捕获模块
**功能：** 捕获系统音频

**技术要求：**
- 库：pyaudio / sounddevice
- 音频格式：16kHz, 16bit, mono
- 仅实时处理，不保存录音
- 区分系统音频和麦克风输入

---

## 3. 非功能需求

### 3.1 性能要求
- CPU 占用：< 15%
- 内存占用：< 2GB
- 响应延迟：< 3 秒（从问题结束到答案显示）

### 3.2 兼容性要求
- 操作系统：Windows 10/11
- 面试平台：腾讯会议
- Python 版本：3.9+

### 3.3 安全性要求
- 音频不保存到磁盘
- API Key 本地加密存储
- 无网络日志上传

## 5. 配置项

### 5.1 用户配置
```yaml
# config/settings.yaml
audio:
  source: "system"          # system / microphone
  sample_rate: 16000
  channels: 1

recognition:
  engine: "whisper"         # whisper / api
  model: "base"             # tiny / base / small / medium
  language: "zh"

ai:
  base_url: "https://token-plan-cn.xiaomimimo.com/v1"
  api_key: "your-api-key"
  model: "gpt-4"
  max_tokens: 2000

ui:
  hotkey: "ctrl+b"
  opacity: 0.9
  font_size: 14
  position: "top-right"

filter:
  min_question_length: 10
  ignore_patterns:
    - "你好"
    - "稍等"
    - "下一个"
```

## 6. 用户流程

### 6.1 启动流程
1. 用户启动程序
2. 加载配置文件
3. 初始化音频捕获
4. 加载 Whisper 模型
5. 显示系统托盘图标
6. 等待快捷键触发

### 6.2 面试流程
1. 用户打开腾讯会议
2. 按 `Ctrl + B` 显示悬浮窗
3. 面试官开始提问
4. 系统自动识别问题
5. 生成并显示答案
6. 用户参考答案回答
7. 按 `Ctrl + B` 隐藏悬浮窗

### 6.3 结束流程
1. 用户关闭程序
2. 释放音频资源
3. 清理临时数据

## 7. 风险与限制

### 7.1 技术风险
- Whisper 模型需要 GPU（或使用 API）
- 音频捕获可能受系统权限限制
- 腾讯会议音频输出可能需要虚拟音频设备

### 7.2 使用限制
- 仅支持 Windows 系统
- 仅支持腾讯会议
- 需要稳定的网络连接（API 调用）

### 7.3 缓解措施
- 提供 CPU/GPU 两种模式
- 提供详细的权限设置指南
- 支持离线模式（本地模型）
